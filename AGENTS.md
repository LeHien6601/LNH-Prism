# LNH Prism Agent Router

## Mission

Prism V2 compiles game-owned semantic UI specifications into validated wireframe evidence and engine-specific generated views. It does not create production artwork.

Always preserve deterministic output, editable geometry, stable IDs, independent effects, material provenance, reproducible export metadata, and the review-reference boundary.

The legacy renderer and Production Lab remain supported historical evidence, but new V2 packages must not import their art, material, reconstruction, showroom, or milestone implementation paths.

## Route work

Load only the matching repository-local skill in `.agents/skills/`:

- Ordinary scoped coding: `scoped-coding`; add `game-ui-rendering` or `visual-validation` only when applicable.
- `Next:` or `Apply Review:`: `managed-project-task` plus any domain skill.
- `Guide:` or `Review:`: `project-review`.
- `Push:` or an explicitly requested release: `release-delivery`.

Run `npm run agent:brief -- --json` before managed work when a compact project snapshot is sufficient. Read detailed project records only when the selected skill requires them.

## Scoped coding

- Inspect the closest instructions and only files relevant to the request.
- Read project records only when the change affects their contract, status, dependencies, or architecture.
- Search and summarize before broad reads. Use deterministic queries for inventories, comparisons, and audits; report counts, failures, and affected paths only.
- Preserve unrelated changes, add focused tests, and validate proportionately.
- Do not commit or push unless explicitly requested.

## Managed project work

- Follow the selected skill's full governance, task eligibility, evidence, status-update, Conventional Commit, and push rules.
- Do not start human-decision or blocked work autonomously.

## Reporting and safety

Report outcome, validation actually run, blockers, and required managed-task handoff. Never force-push, rewrite history, discard unrelated work, or use AI-generated full-screen images or review-reference pixels as final component sources.
