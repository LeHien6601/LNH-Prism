# Managed project task
Run `npm run agent:brief -- --json`, then read the overview, relevant module, change control, and roadmap. Select only the authorized agent-ready task.
Implement one coherent task, run its stated validation, update required records, review the diff, commit with Conventional Commits, and push the configured upstream. Do not choose a human decision or blocked task.
