# M2-S2 Neon Alloy Evidence

This directory contains deterministic, isolated SVG previews for the three reusable Neon Alloy sources:

- `alloy-grain-isolation.svg` — tile-safe neutral surface grain.
- `alloy-circuit-pattern-isolation.svg` — tile-safe circuit pattern.
- `alloy-holo-accent-isolation.svg` — transparent clamp-safe accent.

Generate with `npm run prepare:m2-s2-evidence` and verify with `npm run validate:m2-s2-evidence`. The source descriptors and their SHA-256 receipts are in `materials/neon-alloy/` and `specs/examples/neon-alloy-materials.json`. These previews are material isolation evidence only; they are not component assets.
