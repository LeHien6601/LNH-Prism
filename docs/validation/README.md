# Validation Records

This directory contains reusable review rubrics and completed validation evidence. A rubric defines how a milestone is judged; a validation record proves a specific asset set was reviewed.

| Item | State | Purpose |
|---|---|---|
| [V1 visual-review rubric](V1_VISUAL_REVIEW_RUBRIC.md) | 🟢 Approved | Judge reusable structured SVG quality for the first deterministic component set |
| [V1 evidence package](evidence/v1-neon-core-core-components/README.md) | 🟢 Complete | Map V1-E01 through V1-E06 to reproducible evidence and review surfaces |
| [V1 validation record](records/v1-neon-core-core-components.md) | 🟢 Passed at `93/100` | Preserve the original failed review, corrected traceability evidence, appended re-score, and approved final gate |
| [V2 visual-review rubric](V2_VISUAL_REVIEW_RUBRIC.md) | 🟢 Approved | Govern Neon Market material-reuse evidence, scoring, blockers, and revalidation; Conditional Pass is `82–84` |

Do not mark a milestone gate complete by creating a rubric. Store the completed scorecard, evidence links, defects, corrective actions, and revalidation result beside the rubric after the real validation occurs.
