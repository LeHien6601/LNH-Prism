# Validation Records

This directory contains reusable review rubrics and completed validation evidence. A rubric defines how a milestone is judged; a validation record proves a specific asset set was reviewed.

| Item | State | Purpose |
|---|---|---|
| [V1 visual-review rubric](V1_VISUAL_REVIEW_RUBRIC.md) | 🟡 Draft | Review the first deterministic Button, Panel, and Progress Bar set |

Do not mark a milestone gate complete by creating a rubric. Store the completed scorecard, evidence links, defects, corrective actions, and revalidation result beside the rubric after the real validation occurs.
