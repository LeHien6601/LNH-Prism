# ADR-020 — Stage production-fidelity systems as M9

## Status

Accepted — 2026-07-18

## Context

The approved strategic plan identifies missing reusable production-fidelity systems: edge stacks, material responses, seeded variation, ornament/focal frameworks, typography treatments, shared lighting, three-distance review, and visual scoring separate from technical correctness.

M8-A4 is already bounded to render the approved cold-material and editable-focal contracts into a versioned asset package and showroom. Expanding that task would combine multiple independent renderer, schema, validation, and art-direction changes into one uncontrolled task.

## Decision

Approve **Option B**: keep M8-A4 bounded. After the M8 package and V8 review establish a real visual baseline, begin **M9 — Frostbound production-fidelity systems** before Volcanic Forge or any other multi-style transfer work.

M9 must split the strategic-plan capabilities into coherent agent-ready slices. It must preserve deterministic outputs, explicit/versioned seeds, editable structure, M7/M8 lineage, concept-pixel boundaries, and engine-neutral delivery.

## Consequences

- M8-A4 remains the next agent-ready task and is not expanded.
- M9 planning begins only after M8-A5 records the visual/technical result and identifies the smallest ordered system slices.
- No multi-style transfer or style-authoring work starts before M9 has addressed Frostbound’s production-fidelity gaps.
