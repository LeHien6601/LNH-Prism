# ADR-019 — Start Frostbound-aligned M7 refinement

## Status

Accepted — 2026-07-18

## Context

M7 passed at `90.5/100` with no blocker. Its angular silhouette, deterministic structure, material reuse, and asset-only handoff are complete. The V7 review retained two non-blocking comparative observations: the family reads more forge/tech than Frostbound's ice/crystal atmosphere, and its interior plate pattern could leave more room for a reward focal point.

## Decision

Start a bounded **M8 — Frostbound-aligned angular refinement** track.

M8 retains M7's sharp wide-hex geometry, seven-component modular boundaries, deterministic SVG/PNG outputs, showroom requirement, and engine-neutral handoff. It may refine only the following visual controls:

- a reusable ice/crystal material treatment and cold-blue palette variant;
- a stronger, independently editable reward-emblem/focal treatment;
- calmer or more selective panel interior plate detail;
- related deterministic state and hierarchy tuning.

The Frostbound concept remains comparative evidence only. Its pixels, crops, traces, and hashes remain prohibited in material sources and production outputs. Unity and other engine integration remain out of scope.

## Consequences

- M8-A1 is agent-ready: draft the bounded implementation specification and review rubric.
- The specification must define component/material scope, layer boundaries, acceptance criteria, evidence, score thresholds, and automatic blockers before rendering starts.
- M8 must preserve M7 package compatibility unless an explicitly documented versioned successor is required.
